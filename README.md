# Special-password

**神奇的密码** —— 一款纯本地离线运行的加密密码管理器。


## 📖 简介

这是一款无需联网、不上传任何数据的密码管理器。所有密码数据均存储在手机本地，采用 AES-GCM 加密算法保护你的隐私安全。支持密码的增删改查、导入导出、搜索排序、批量管理等完整功能，界面采用 Material 3 设计语言，流畅美观。


## ✨ 功能特性

### 🔐 安全加密
- 主密码锁屏保护，每次打开应用需验证
- 支持修改主密码
- 密码强度实时检测（弱/中/强/超强/离谱强）
- 首次使用验证对话框（防倒卖机制）

### 🔐 加密方案与安全性说明

从 **v1.2 正式版** 起，本软件采用 **AES-256-GCM + PBKDF2** 的组合加密方案。

- **主密码保护**：通过 PBKDF2（100,000 次迭代 + 随机盐）派生加密密钥，不存储明文。
- **数据加密**：所有密码条目使用 AES-256-GCM 对称加密存储，密钥长度 256 位。
- **安全性说明**：主密码强度决定整体安全水平，建议设置 ≥ 8 位、包含大小写字母和数字的主密码。
- **密码条目**：AES-256-GCM 加密强度在当前计算能力下不可暴力破解。

### 📁 密码管理
- 添加、编辑、删除密码条目
- 密码列表卡片显示，支持拖动排序
- 置顶功能（置顶卡片独立排序，蓝色标签标识）
- 批量选择（长按进入选择模式，支持全选/批量删除）
- 搜索功能（实时过滤，匹配文字高亮显示）
- 空状态提示（无密码 / 搜索无结果）
- 列表显示密码总数及最后修改时间
- 添加/编辑页面自动聚焦输入框，逐字段校验

### 📤 导入与导出
- 导出密码为 AES-GCM 加密备份文件
- 导入备份文件时支持选择置顶或非置顶方式
- 导入对话框采用 CheckBox 选择，操作直观

### 🎨 界面与体验
- Material 3 设计语言（动态配色、弹性动效、大圆角卡片）
- 主题色自定义（6 种预选颜色 + RGB 手动调色）
- 沉浸式状态栏，Toolbar 跟随主题色
- 详情页预览返回手势（左边缘拖拽预览上一页）
- 更新日志弹窗支持长按复制
